# Передача следующему агенту
Вставьте новому агенту:
> Продолжи Mutant Lab в этом репозитории. Прочитай AGENTS.md, docs/STATUS.md, docs/ROADMAP.md, docs/ARCHITECTURE.md и docs/NETWORK.md. Используй skills/mutant-lab-development/SKILL.md. Возьми первый незавершённый критерий приёмки. Сначала проверь код и git status, сохрани чужие изменения. Реализуй ограниченный этап, выполни доступные проверки и обнови STATUS с доказательствами и следующим шагом. Все субагенты должны работать на gpt-5.6-sol. Не заявляй о тестах Roblox Studio, которые не запускал.

## Где искать ответы
- Scope и последовательность этапов: ROADMAP.
- Реализованное и непроверенное: STATUS.
- API сети и форма состояния: NETWORK.
- Модули, сохранения, проектные решения: ARCHITECTURE.
- Баланс: ECONOMY и src/shared/Config.
- Проверка в игре: MANUAL_TESTS.
- Команды запуска: README.

## Что записать перед завершением работы
1. Какие критерии закрыты и какие файлы изменены.
2. Точные команды, результат и ограничения проверки.
3. Найденные дефекты, оставшиеся риски и ближайшая конкретная задача.
4. Commit hash; если нет коммита — почему.
5. При реальном Studio-тесте: дата, версия place/commit, режим памяти/DataStore, число клиентов, результат каждого сценария.

Обязательных решений в истории чата нет: если появилось новое решение, перенесите его в эти файлы. Не записывайте в репозиторий секреты/личные идентификаторы аккаунтов.
