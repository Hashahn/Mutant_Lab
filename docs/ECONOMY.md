# Экономика v0.1
Источник истины: src/shared/Config/GameConfig.luau и MutantConfig.luau.
| Параметр | Значение |
|---|---:|
| Стартовые BioCoins | 100 |
| Бесплатные Blob за весь tutorial | 2 |
| Цена дальнейшего Blob | 50 |
| Начальные слоты | 6 |
| Merge двух Blob | 0 |
| Blob: сила / награда | 10 / 15 |
| Toxic Blob: сила / награда | 25 / 35 |
| Plasma Blob: сила / награда | 60 / 85 |
| Длительность боя | 6 секунд |
| Максимальный баланс | 1 000 000 000 |

Sources: стартовый баланс и завершённые сервером бои. Sink: покупка Blob. Бесплатные существа учитываются отдельным счётчиком и не выдаются заново при входе. Release не приносит валюты.
После обычного обучения с Toxic баланс 135; после первой платной покупки — 85. Три боя Toxic Blob дают 105 и покрывают двух Blob за 100.
Это тестовый баланс: неизрасходуемые мутанты и бесконечные бои допускают накопление валюты, поэтому схема не предназначена для Robux-экономики без отдельного балансирования.
Одновременно идёт один бой; сервер определяет тип, срок и награду. Клиент не завершает бой и не задаёт суммы.

Альтернативное обучение: 4 Blob (2 бесплатных + 2 за100) → Plasma при балансе0 → первый бой даёт85 и завершает обучение. Merge двух Toxic бесплатный.
BasePower пока не участвует в серверном расчёте урона. HP и цифры ударов — клиентская визуализация; сервер выдаёт награду по таймеру.
