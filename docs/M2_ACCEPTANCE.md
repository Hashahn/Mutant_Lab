# M2 — приёмка сохранений
Статус: НЕ ВЫПОЛНЕНО. Это план, не отчёт о прохождении.

## Подготовка
1. На исправленном commit пройти новые Studio-регрессии из MANUAL_TESTS: ранний Plasma и согласованный урон.
2. Использовать отдельную опубликованную test experience, не вторую place внутри production experience.
3. Зафиксировать commit, дату, test universe ID (game.GameId), place ID, режим и тестовые аккаунты. Universe ID и place ID различаются.
4. Проверить доступность инструментов Studio MCP у выполняющего агента. Наличие навыка и включённый переключатель Studio сами по себе не подтверждают соединение.
5. В src/server/Config/PersistenceConfig.luau безопасные значения по умолчанию: StudioPersistence.Enabled=false, UniverseId=0. Для проверки явно указать ID тестовой experience, включить StudioPersistence.Enabled и API access только там; изменения синхронизировать из исходников.
6. Текущие namespace различаются: StudioNamespace=studio-test-v1, LiveNamespace=development-v1, DataStoreName=MutantLabProfiles. Сравнивать повторные входы в одном режиме: переноса между Studio и опубликованным сервером сейчас нет.

## Проверка
- Снять состояние после обучения и покупки: BioCoins, ID и типы мутантов, Tutorial и FreeBlobsClaimed.
- Перезапустить сервер и сравнить: всё сохранено, бесплатные Blob повторно не выданы.
- Повторить для Plasma-профиля; выйти в середине боя и убедиться, что незавершённая награда не появилась после входа.
- Проверить два разных аккаунта и отдельность их данных.
- По MANUAL_TESTS проверить конкурирующие сессии, сбои Load/Save, истечение lease и повреждённые/будущие версии. Fault injection проводить на специальных тестовых ключах, не на реальных профилях.
- Сохранить логи и результаты каждого сценария в STATUS. Вернуть Studio в memory-режим после теста, если постоянный тестовый режим не согласован.

## Готовность
Один успешный rejoin не закрывает M2. Все непройденные пункты DataStore в MANUAL_TESTS остаются открытыми; тесты имитации хранилища не заменяют реальную приёмку.
