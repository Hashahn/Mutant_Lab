# Mutant Lab — правила для агентов
Перед изменениями прочитайте docs/STATUS.md, docs/ROADMAP.md и docs/ARCHITECTURE.md. Контракт сети: docs/NETWORK.md.
- Исходники в Git — источник истины; Studio используется для проверки, не для скрытых изменений скриптов.
- Валюта, инвентарь, обучение и награды изменяются только сервером. Клиент отправляет намерение и ID, никогда цену/награду.
- Не выполнять DataStore-тесты в production experience. Studio по умолчанию использует память. Ошибка загрузки не равна новому игроку.
- Изменения состояния внутри одной операции не должны yield. DataStore и аналитика находятся за пределами таких операций.
- Работайте по одному milestone. Текущая версия уже содержит Blob, Toxic Blob и Plasma Blob. Не добавляйте торговлю, Robux-покупки, PvP или следующие tiers без отдельного задания.
- После работы обновите STATUS: изменения, реально выполненные команды, оставшиеся проверки, конкретный следующий шаг. Не отмечайте Studio-тесты пройденными без запуска Studio.
- Передача работы: docs/HANDOFF.md. Навык продолжения: .agents/skills/mutant-lab-development/SKILL.md.
- При параллельной работе согласуйте владельцев файлов и интерфейсы; не перезаписывайте чужие изменения.
- Перед коммитом: сборка Rojo, Luau-тесты и форматирование (команды в README). Если инструмент недоступен, укажите это.


- Все субагенты этого проекта должны запускаться на gpt-5.6-sol (явное требование владельца).
